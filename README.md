# Ukrainian Orthodox Church Ingolstadt

A modern and responsive website for the Ukrainian Orthodox parish in Ingolstadt, Germany.

The website was designed and developed from scratch with a focus on clean UI, responsive design, reusable components, and a clear presentation of parish information.

 **Live Demo:** [https://ukrainian-church-ingolstadt.vercel.app](https://ukrainian-church-ingolstadt-au1f.vercel.app)/

---

## About the Project

This project is a website for a real Ukrainian Orthodox parish in Ingolstadt.

The goal was to create a modern, accessible, and easy-to-navigate website where visitors can learn more about the parish, its history, church services, and the Sacraments of the Orthodox Church.

The project combines a custom visual design with a reusable component-based architecture, making it easy to maintain and extend in the future.

---

## Features

- Fully responsive design for desktop, tablet, and mobile
- Responsive header and mobile navigation
- Dropdown navigation for the Sacraments
- Dedicated pages for all seven Sacraments
- Dynamic navigation depending on the current page
- Smooth anchor navigation between page sections
- Reusable content and card components
- Interactive FAQ sections
- Parish history section
- Responsive images and layouts
- Custom UI and typography
- Production deployment with Vercel

## Project Structure

The project follows a reusable component-based architecture.

Shared UI elements such as the Header, Footer, Hero, FAQ, buttons, containers, quotes, and content sections are implemented as reusable React components.

Content for individual Sacraments is separated from the presentation logic, allowing multiple pages to share the same components while displaying different content.

This approach reduces code duplication and makes the website easier to maintain and expand.

---

## Sacrament Pages

The website includes dedicated pages for:

- Baptism
- Chrismation
- Eucharist
- Confession
- Marriage
- Holy Orders
- Anointing of the Sick

Each page uses shared components while maintaining its own content and navigation structure.

---

## Responsive Design

The interface was developed with both desktop and mobile users in mind.

Navigation, dropdown menus, content cards, typography, spacing, and page layouts adapt to different screen sizes to provide a consistent user experience across devices.

---

## Development

The project is developed with Next.js and TypeScript.

The source code is managed with Git and GitHub, while Vercel is used for deployment and previewing production builds.

New deployments are automatically created when updates are pushed to the repository.
